# Nossos Conteúdos (Não sei se será o nome final)

### Usaremos esse repositório para compartilhar aquilo que achamos importante e queremos compartilham um com o outro :)

### Nesse repositório dividiremos os conteúdos em pastas:
- [obsidian](obsidian)
- [aulas](aulas)
- [códigos](codigos)

---

## Obsidian

#### A pasta obsidian usaremos para enviar nossos arquivos que temos no obsidian, para compartilhar nossas notas e canvas que estão lá.

---

## Aulas

#### A pasta aulas será para enviar atividades ou própria matéria passada em sala para que possamos ajudar um ao outro nas atividades.

---

## Códigos

#### A pasta codigos será utilizada para fazermos códigos entre nós dois, seja para prática ou até mesmo desenvolver uma ideia que poderá ser passada adiante

---

# Padrão de Commit

#### Sinceramente não é necessário, mas é bom para manter o costume :P

- [aulas][SO]: Adicionado explicação sobre Regex
